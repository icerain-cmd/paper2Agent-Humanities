# Phase 2 / Phase 3 Comparison

| Dimension | Phase 2 | Phase 3 |
|---|---|---|
| dialogue wording | controlled, prewritten specifications | must be generated by a live ModelAdapter |
| source retrieval | selected controlled propositions | inspectable runtime retrieval traces |
| role of old artifacts | primary PoC output | regression-only; not reachable by runtime generation |
| model requirement | none | real callable runtime required |
| no-model behavior | controlled artifacts still executable | explicit BLOCKED; no fake dialogue |
| verification | provenance + semantic review | same gates retained before publication |
| edition/corpus firewalls | enforced | enforced in runtime evidence packets and publication |
| evaluation | controlled D/E/F | live D/E/F only after real runtime generation |

Similarity to Phase-2 wording is never used as correctness. Future live comparison should ask whether the same issue/evidence/relation was independently rediscovered, whether new issues arise, whether unsupported claims were introduced, and whether abstention occurred appropriately.
